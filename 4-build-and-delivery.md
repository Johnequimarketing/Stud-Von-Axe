# 4. Build and delivery

## How to build it

Use Claude Code to build three static homepage concepts and deploy each one to Vercel. We want clickable preview links, not screenshots, so the client can scroll through them on their own phone.

- Static HTML and CSS, or a simple framework if you prefer. No CMS at this stage.
- One file per direction, or one project with three routes. Whichever is faster.
- All colours as CSS variables at the top. The gold Pantone is still coming and we swap it in one place.
- Self host the fonts or load them properly. Check the licence on anything that is not Google Fonts.
- Real content, not lorem ipsum. Pull the horses, genetics lines, photos and news items from studvonaxe.it so the client sees their own material.

## Responsive

Test at 390, 768 and 1440. The card sections and the genetics lines are where it breaks, so start there.

## What to hand in

Three Vercel preview links, posted in the task. Add a short note per direction saying what you were going for, so we can talk the client through it rather than just showing them three pages.

If one direction turns out stronger than the others while you build, say so. Your read is useful.

## Ask if you are stuck

Anything unclear in the briefing, ask straight away rather than guessing. The client is specific about what they want and it is cheaper to check now than to redo it later.
