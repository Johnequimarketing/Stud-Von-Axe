# Stage 11: Cookies, analytics and going live

Everything that has to be arranged around the site before it can be public.

**Planned:** Wed 30 Sep to Thu 01 Oct 2026

## Steps

1. CookieYes: install, configure, and put the banner in the client's own categories.
2. Google Analytics 4 and Google Search Console: property, tag, and the sitemap.
3. Rewrite the privacy page: it currently states that the site sets no cookies and runs no analytics, and after this stage that is no longer true.
4. Rank Math: sitemap, robots, and the social image for each of the seven main pages.
5. Check that staging is on **noindex** and that the live site is not.
6. Redirects from the old web addresses, if the client has an old site that is being replaced.
7. Performance: LiteSpeed cache is already on. Check that it does not cache the filter bar's results.
8. Backup and an update policy.

## Worth knowing

- **The language switcher has nothing behind it.** The footer shows English, Italiano, Français and Deutsch on all 122 pages as plain labels with no links. Four dead controls per page. There is no translation plugin in any stage, so a decision is needed: either WPML/Polylang and Italian becomes a project of its own, or the switcher comes out until there is something to switch to. Italian is the client's own language, so this is worth putting to them properly.
- There is no cookie banner and no analytics on the site today, so nothing has to be removed first. This stage adds them from nothing.
- The contact form and the enquiry forms only start sending in stage 8. If that stage is not finished, do not go live: a contact page whose form does nothing is worse than no form.
