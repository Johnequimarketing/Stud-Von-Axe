# Stage 10: Check everything

Walk the whole site against the live preview and write down what does not match, before anything is switched on for the public.

**Planned:** Mon 28 Sep to Tue 29 Sep 2026

## Steps

1. Open all 122 pages of the live preview beside staging. The list is in `page-list.md`.
2. Per page: heading text, section order, photographs, and every link.
3. Check the five archives on all three filters at once: type a name, press a chip, choose a select. The three have to narrow the list together, not replace each other.
4. Check the embryo archive again on the order: implanted first, then frozen.
5. Check every single at 1440, 768 and 390 pixels.
6. Rank Math: title and description on the seven main pages and on the six archives.
7. Check that nothing is in the WordPress editor. All copy is in ACF fields; if a page shows text that is not in a field, it was typed in by hand and it will be lost on re-import.
8. Write down what does not match. Do not fix it in this stage — collect it first, then we decide together what is a fault and what is a change.
